Features

Built local-first, tuned to you

The parts most AI tools treat as an afterthought: organization, consistency, and control over your own data.

Local-first storage

Conversations live in a database on your disk. Connect Turso when you want them on every laptop - you own the data either way.

Any provider

OpenAI, DeepSeek, Ollama, LM Studio, Opencode Go, or any OpenAI-compatible endpoint. Switch models without switching apps.

Custom instructions

Define format, tone, and constraints once. Every reply follows your rules instead of platform defaults.

Skills

Reusable knowledge blocks for projects, conventions, and domains. Activate exactly what each conversation needs.

Custom agents

Combine instructions and skills into named profiles and jump between contexts with a single slash command.

Agent memory

An agent that grows with you. Tell it your name, preferences, and decisions once - it remembers across conversations and recalls only when relevant. Off by default, and always yours to clear.

Tags, pins, and search

Tag conversations, pin the ones that matter, and search everything from one place. No more untitled chat 47.

Build your agent

Instructions + Skills = Agent

Stack global rules with reusable skills, wrap them into a named agent, and call the whole thing with a slash.

/ agent

  • /agent writing-partner

    Agent - instructions + 2 skills

  • /skill no-emojis

    Skill - formatting rules for every reply

  • /instructions concise-format

    Instruction - prepended to every message

Enter to activate
